# CURRENT — Brand guidelines

## Project identity

- **Project name:** MAME Libretro Current
- **Visual brand:** CURRENT
- **Descriptor:** Unofficial experimental Libretro core
- **Tagline:** O código evolui. A história continua.
- **Short description:** An experimental community fork focused on keeping the MAME emulation code current while preserving the Libretro integration.

Use “MAME Libretro Current” when the full project lineage needs to be explicit. Use “CURRENT” as the visual signature. Do not present the project as an official MAME or Libretro release, and do not imply endorsement by either project.

## Brand idea

CURRENT represents two things at once: an electrical signal from the machines being preserved, and a continuously moving stream of upstream development. The pixel blocks represent historical systems; the waveform represents active engineering and ongoing integration.

## Logo assets

- `logo-current.svg` — primary horizontal lockup for documentation and project pages.
- `logo-mark.svg` — standalone symbol for avatars, icons and small UI placements.
- `banner.svg` — wide header/banner artwork.

The mark and lockup are original artwork created for this fork. They do not reproduce the official MAME or RetroArch logos.

## Typography

- **Display:** Space Grotesk ExtraBold, with Arial/Helvetica as fallback.
- **Technical labels:** IBM Plex Mono, with a monospace fallback.
- Use uppercase, generous letter spacing for compact labels. Keep paragraphs in a neutral sans-serif.

No font files are bundled. Use system or web-safe fallbacks where external fonts cannot be loaded.

## Voice and messaging

Prefer precise, engineering-led language: “upstream sync”, “experimental build”, “Libretro integration”, “tested on RetroArch”. Clearly distinguish upstream MAME version, fork build identifier and test status.

Avoid claims such as “official”, “fully compatible”, “all games working” or “latest MAME” unless each claim is verified. Label untested builds as experimental.

## Trademark and affiliation note

MAME and RetroArch are names of their respective projects. This fork is an independent community experiment and is not an official release or an endorsed product. Keep this disclaimer visible in project descriptions and release notes. Do not use the official MAME logo or imitate its wordmark. Use the MAME name only to identify the upstream software and the technical lineage of this fork. Confirm any additional trademark requirements with the relevant rights holder before commercial use or formal product branding.
